# 總圖不打烊

清大程設 Final Project：第一人稱 3D 恐怖解謎遊戲，舞台是半夜的清大總圖。

期末考前一晚，你跟室友溜進總圖找傳說中的「考古題之書」，室友卻在書架間失蹤了。
每到凌晨 3:00，一切重來——但你會記得上一輪學到的線索。

## 執行

```
pip install -r requirements.txt
python game/main.py
```

需要 Python 3.10 以上。Windows、macOS 都可以，會自動找系統的中文字型。

## 操作

- WASD 移動、滑鼠看、Shift 跑
- E 互動（讀筆記、開門）
- F 開關手電筒
- ESC 離開

## 目前的原型

- 手電筒照亮的黑暗書庫（霧 + 暈影）
- 怪物：被看著、而且在手電筒範圍內時不會動；看不到它時，它沿著走廊格子（BFS）靠近
- 3 張筆記拼出出口密碼
- 凌晨 3:00 時間迴圈：時間到或被抓就重來，讀過的筆記保留

關卡是 `game/main.py` 裡的 `LEVEL` 格子圖：`#` 牆、`B` 書架、`P` 起點、`M` 怪物、`1`–`3` 筆記、`D` 出口。
