# 偷卷仔，給我站住！

清大程設 Final Project：第一人稱 3D 搞笑潛行解謎遊戲，舞台是白天的清大總圖。

期中考週，你和室友說好一起擺爛。傍晚六點，他說要在宿舍睡一整天，IG 限動卻拍到總圖的窗戶。
說好一起擺爛，結果你偷卷？照著他留下的線索一層一層往上找，躲開巡館的館員，在 4F 抓到他、痛扁他。

（原本的恐怖版保留在 `horror-version` 分支。）

## 執行

```
pip install -r requirements.txt
python game/main.py
```

需要 Python 3.10 以上。Windows、macOS 都可以，會自動找系統的中文字型。

## 操作

- WASD 移動、滑鼠看、Shift 跑、Ctrl 躡手躡腳（貼著牆走會沿著牆滑）
- E 互動：準心對著東西，下方會出現「[E] …」提示；痛扁時狂按 E 或滑鼠左鍵
- C 躲到桌子底下／出來
- ESC 回到大廳（大廳可選難度、看故事介紹與操作說明）

## 玩法

- 地圖照清大總圖（旺宏館）官網的樓層平面圖做成 1F–4F，用東南角的樓梯間上下樓（B1 館員專用、5F 以上還在蓋）
- 線索鏈：
  - 1F：聯合櫃臺電腦查室友的預約 → 打開自助取書櫃（每局櫃號隨機），找到 2F 電腦教室的預約單
  - 2F：照校史展示區的提示登入電腦教室的電腦，看到他的搜尋紀錄
  - 3F：視聽聆賞席的錄音帶是他錄的線代重點，最後透露他在 4F（嗶聲數 = 展示櫃第一碼）
  - 4F：室友坐在某張桌子讀書
- 館員（`game/npc.py`）：在走道巡邏，聽到聲音會走過去看；看到你奔跑或太吵會「噓」你，一天警告三次就被請出去
- 室友：低頭讀書時只聽得到跑步聲，每隔幾秒抬頭張望，看到你就抱著書逃到別張桌子。
  趁他低頭時躡手躡腳靠近按 E，或在他逃跑時追上去碰到他，就抓到了
- 痛扁小遊戲：時間內狂按把他打趴就過關，打不夠他會掙脫再逃
- 隱藏結局：湊齊三碼（錄音帶、300 科學類書架上的便條、討論室白板）打開清華書房的展示櫃
- 聲音條：跑步會累積，滿了館員會走過來；按 C 躲到桌子底下館員和室友都看不到你
- 隨機事件（`game/events.py`）：館內廣播、掉書、手機響（會把館員引開）、室友的 IG 限動、遠處閃過室友的背影
- 時間：18:00 到 22:00 閉館，時間到或被請出去就是隔天，留在同一層，查到的線索都記得
- 所有材質和音效都由程式產生（`game/textures.py`、`game/sfx.py`），之後可以換成實景照片

## 程式結構

- `game/main.py`：遊戲流程、線索、每天的循環、痛扁小遊戲
- `game/npc.py`：館員與室友
- `game/minigames.py`：質因數分解牆（2F）、揪團選門（3F）兩個小遊戲
- `game/player.py`：玩家移動（貼牆滑動）與滑鼠視角（macOS 用 relative 模式）
- `game/world.py`：`LEVEL` 格子地圖與 3D 場景生成
- `game/textures.py`：材質產生
- `game/sfx.py`：音效合成
- `game/menu.py`：開始大廳與難度設定（`DIFFICULTIES`）

`FLOORS`（在 `world.py`）每層一張格子圖，圖例：`#` 牆、`W` 窗、`B` 書架、`K` 密集書庫、`T` 閱覽桌、`C` 自習座位、`S` 服務台、
`O` 柱子、`G` 玻璃隔間、`R` 感應閘門、`,` 磨石子地板、`.` 地毯、`P` 起點、`M` 館員起點、`1`–`6` 筆記、`D` 往下的門、`U` 往上的門、`k` 可移動的密集書架。
改格子圖就能改地圖。
