# 總圖不打烊

清大程設 Final Project：第一人稱 3D 恐怖解謎遊戲，舞台是半夜的清大總圖。

期末考前一晚，你跟室友溜進總圖找傳說中的「考古題之書」，室友卻在書架間失蹤了。
每到凌晨 3:00，一切重來——但你會記得上一輪學到的線索。

## 執行

```
pip install -r requirements.txt
python game/main.py
```

需要 Python 3.10 以上。Windows、macOS 都可以，會自動找系統的中文字型。

## 操作

- WASD 移動、滑鼠看、Shift 跑
- E 互動（讀筆記、開門）
- F 開關手電筒
- ESC 回到大廳（大廳可選難度、看故事介紹與操作說明）

## 目前的原型

- 照清大總圖（旺宏館）官網的樓層平面圖做成多層樓（`world.py` 的 `FLOORS`），用東南角的樓梯間上下樓。
  每層都有西南邊的弧形落地窗、北邊的公務區和規律的柱子：
  - 1F：前棟夜讀區（起點，怪物進不來）、聯合櫃臺、自助取書區、資訊島、圓形的知識集展區、輕學區、清沙龍
  - 2F：電腦教室、電腦共學區、校史展示區、熱門書刊、現期期刊、本校學位論文
  - 3F：視聽聆賞席、媒體區、語言學習區、小舞台、簡報練習室、怡嚴音樂聆賞室、發呆區、電視區
  - 4F：中文圖書 000–499、清華故事牆、清華書房、閱覽區、討論室
  - B1：密集書庫（館員專用）
  - 5F、6F 還在做
- 所有材質（地毯、書背、天花板、窗外月光、指示牌、尋人啟事）都由 `game/textures.py` 用程式產生，
  之後可以直接換成實景照片
- 手電筒照亮的黑暗（霧 + 暈影）、會閃爍的壞燈管、灰塵、日光燈嗡嗡聲、心跳、腳步聲（`game/sfx.py` 合成）
- 怪物：被看著、而且在手電筒範圍內時不會動；看不到它時，它沿著走道格子（BFS）靠近，靠近時燈會亂閃
- 1F：讀室友筆記 → 櫃台電腦查預約 → 打開正確的取書櫃拿到館員門卡（每局櫃號隨機）
- 2F：照校史展示區的提示猜出電腦教室的密碼，登入後開通往 3F 的門禁
- 3F：聽視聆賞席的錄音帶，數嗶聲得到第一碼
- 4F：書架上的便條、討論室白板拿到另外兩碼，打開清華書房展示櫃拿到 B1 通行證
- B1 地下書庫：可轉手輪移動的密集書架，照線索打開正確走道找到《考古題之書》
- 聲音條：跑步會累積，滿了它就聽到你、速度變快；按 Ctrl 躡手躡腳不出聲
- 躲藏：靠近桌子按 C 躲到底下，它找不到你，會在樓層裡亂晃，但時間照樣走
- 手電筒電池：開著會耗電，沒電就看不清它；每層地上有 3 顆電池
- 隨機驚嚇事件（`game/events.py`）：停電、書從架上掉下來、閉館廣播、遠處閃過室友的身影、手機鈴聲
- 凌晨 3:00 時間迴圈：時間到或被抓就重來，留在同一層，拿到的東西和讀過的筆記保留

## 程式結構

- `game/main.py`：遊戲流程、怪物、迴圈、互動
- `game/world.py`：`LEVEL` 格子地圖與 3D 場景生成
- `game/textures.py`：材質產生
- `game/sfx.py`：音效合成
- `game/menu.py`：開始大廳與難度設定（`DIFFICULTIES`）

`FLOORS`（在 `world.py`）每層一張格子圖，圖例：`#` 牆、`W` 窗、`B` 書架、`K` 密集書庫、`T` 閱覽桌、`C` 自習座位、`S` 服務台、
`O` 柱子、`G` 玻璃隔間、`R` 感應閘門、`,` 磨石子地板、`.` 地毯、`P` 起點、`M` 怪物、`1`–`4` 筆記、`D` 往下的門、`U` 往上的門、`k` 可移動的密集書架。
改格子圖就能改地圖。
